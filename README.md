# CANVAS FIGHTERS

**ブラウザを開くだけで遊べる、本格派の2D対戦格闘ゲーム。**

インストールもアカウント登録もいりません。ページを開けば、すぐに戦いが始まります。
個性がまったく違う15人のファイターから1人を選び、CPUと腕をみがき、オンラインでほかのプレイヤーと競い合いましょう。

▶ **プレイはこちら:** https://canvas-fighter.onrender.com
(サーバーがしばらく使われていないと、最初の読み込みに1分ほどかかることがあります)

---

## こんなゲームです

CANVAS FIGHTERS は、HTML5 の Canvas で描かれた2D格闘ゲームです。
キャラクターの動き、技のエフェクト、K.O. の演出まで、すべてがブラウザの中で動いています。

見た目は手軽でも、中身は本格的です。
技にはフレーム単位の「前隙・持続・後隙」があり、シールド、ジャストガード、受け流し、投げ、コンボ、ゲージ技、超必殺技と、格闘ゲームらしい読み合いがそろっています。
初めての人は「Z で攻撃、A で必殺技」だけでも楽しめます。慣れてきたら、フレームを意識した差し合いやコンボ研究にも踏みこめます。

## ゲームモード

### オフライン
| モード | 内容 |
|---|---|
| **CPU対戦** | CPU と1対1で戦います。相手のキャラ(ランダムも可)、CPU のレベル(0〜10)、ステージを選べます。レベル6以上は相手の隙を見てコンボを決めてくる上級CPUです。 |
| **トレーニング** | 体力が減っても K.O. しない練習モードです。食らい判定の表示、入力履歴、フレーム表、一時停止とコマ送り、相手の行動設定(ガード・反撃など)、操作キャラの入れ替えができます。コンボ練習や技の研究に最適です。 |
| **CPU観戦** | CPU 同士の試合を見るモードです。左右のキャラとレベルを選べて、早送りもできます。キャラの動きを研究したいときに。 |

### オンライン
| モード | 内容 |
|---|---|
| **ランクルーム** | 実力の近いプレイヤーと自動でマッチします。勝つと RP(ランクポイント)が +25、負けると −18。 |
| **カジュアルルーム** | RP の変わらない気軽な対戦です。待っている人と自動でマッチします。 |
| **プライベートルーム** | 4文字のルームコードを作って友だちに伝えれば、その人とだけ対戦できます。 |

オンライン対戦は、格闘ゲームで定番の **ロールバック方式** です。
相手の入力が届く前は動きを予想して先に進め、予想が外れたときはなめらかに補正するので、通信の遅れを感じにくくなっています。
入力の遅れは2人とも同じ 4F に固定しているので、設定の違いでどちらかが有利になることはありません。

## 操作方法(初期設定)

| キー | 動作 |
|---|---|
| ← → | 移動(同じ方向に押し続けると走り、2回押しでダッシュ) |
| ↓ | しゃがみ(しゃがみ受け流し) |
| ↑ | 上方向の入力(対空技など) |
| Space / C | ジャンプ(空中でもう1回ジャンプできる) |
| Z | 攻撃 |
| A | 必殺技 |
| X | シールド(押している間) |
| G | 投げ |
| Z + A 同時 | ゲージ技 |
| ↓ + Z + A | 超必殺技 |
| S + A | 本体の必殺(メイ＆ロロ専用) |
| 空中で ←← / →→ | 空中ダッシュ(ハヤテ専用) |
| Esc | メニューへ戻る |

**方向キーとの組み合わせで技が変わります。**
- 地上: Z / ↓Z / ↑Z / 前Z / 後ろZ / ダッシュ中Z、A / 前A / 後ろA / ↑A / ↓A
- 空中: Z / 前Z / ↑Z / ↓Z

さらに、方向キーを順番に入れてからボタンを押す「コマンド技」もあります。
設定の「簡単コマンド」を ON にすると、コマンドの途中の斜め入力を省略できます。
キー配置は設定画面で自由に変えられ、1つの操作に2つまでキーを割り当てられます。

## バトルシステム

### 攻めの基本
- **コンボ:** 技が当たったら、より強い技でキャンセルしてつなげられます。ただし、同じ技の繰り返しやヒット数が増えるとダメージが下がるので、ルートの工夫が大切です。
- **当たる部位:** 頭・胴・腕・脚で、のけぞりの長さが変わります。足を狙う技は硬直が長くなります。
- **ダッシュ:** 前ダッシュとバックダッシュには、出始めに短い無敵があります。攻撃をすり抜けたり、間合いを外したりできます。
- **投げ:** シールドで固まった相手を崩す手段です。前・後ろ・上・下で投げ分けられ、後ろ投げは立ち位置が入れかわります。

### 守りの基本
- **シールド(X):** 攻撃を受け止めて、体力の減りを防ぎます。ただし、受けるたびにシールドが削れ、0になるとガードブレイクして長い間動けなくなります。
- **ジャストガード:** 攻撃が当たる直前にシールドを張ると成功します。相手は大きな隙をさらし、こちらはすぐ動けて、飛び道具は跳ね返せます。読みが当たったときの最大のご褒美です。
- **しゃがみ受け流し:** しゃがんでいるときに攻撃を受けると、自動で受け流してダメージと吹っ飛びを大きく減らします。ただし下段攻撃は受け流せません。
- **空中受け流し:** 空中でコンボを受けているときに使うと、抜け出すチャンスが作れます。

### SP ゲージ
全キャラ共通のゲージです。時間の経過、攻撃を当てる・受ける、ガード、ジャストガード、受け流しの成功でたまります。
- **ゲージ技(Z + A):** ゲージを少し使う強力な技です。無敵やアーマーを持つ技もあります。
- **超必殺技(↓ + Z + A):** ゲージを大きく使う最強の技です。発動すると画面が暗転し、スポットライトの中で技名が表示される特別な演出が入ります。

どちらも通常の技からキャンセルでつながるので、コンボの締めにも使えます。

### ステージ
| ステージ | 特徴 |
|---|---|
| **道場** | ふつうのステージです。 |
| **氷原** | 床が滑ります。止まりにくく、間合いの管理が難しくなります。 |
| **月面** | 重力が低く、ふわっと高く跳べます。空中戦が中心になります。 |
| **火山** | ときどき間欠泉が噴き出してダメージを受けます。 |

## やり込み要素

- **コインとショップ:** 試合をするとコインがもらえます(勝ち +60 / 負け +15)。コインでスキンを買えます。
- **スキン:** 各キャラに、色違いではなく衣装ごと着がえる3着のスキンがあります(白い道着、バイキング、真紅の吸血姫、ネオンサイバーなど)。ショップでは試着もできます。見た目だけが変わり、性能は同じです。
- **実績と称号:** 連勝、パーフェクト勝利、大逆転、短時間決着、各キャラ・各ステージでの勝利など、150以上の実績があります。解除するともらえる称号は、プロフィールや結果画面に表示されます。
- **戦績とプロフィール:** 勝率、連勝記録、キャラごとの成績などが記録されます。
- **リプレイ:** 試合を保存して、あとから何度でも見返せます。お気に入り登録、メモ、並べ替え、絞り込みもできます。1試合わずか数KBで、最大30件まで保存できます。

## 設定

- キー配置(メインとサブの2つまで)
- 簡単コマンド ON / OFF
- ヒット時の画面の揺れ ON / OFF
- 対戦中の操作説明 ON / OFF
- 画質(低・中・高・最高。重いときは下げてください)
- フレームレート(30fps / 60fps)

設定や戦績、コイン、リプレイはブラウザに保存されるので、次に開いたときも続きから遊べます。

## サーバーを自分で動かす場合

ゲームの配信とオンライン対戦の中継は、リポジトリの直下にある `server.js`(Node.js)が行います。

```
npm install
npm start
```

起動すると、`http://localhost:3000` でゲームが開きます。
Render などのサービスで Web Service として動かせば、オンライン対戦もそのまま使えます。
日本から遊ぶ場合は、サーバーの地域を Singapore にすると通信が速くなります。
